# 状态机清单（web-monitor · useRealtimeStream + 大屏页）

> 状态×迁移×用例映射，覆盖率计算依据。基准：FTDD useRealtimeStream 状态机 + PRD V1 AC。

## 客户端连接状态机（单 appKey 通道）

| 状态 | 进入条件 | 视觉表现 | 用例 |
|---|---|---|---|
| idle | 初始 / 无 appKey | —（引导态判断前置） | 单测 AC-008 |
| loading | 开始连接 | 骨架/加载指示 | 单测覆盖（mock 瞬时，E2E 难捕捉） |
| ok | 快照到达且 failure=ok | 七区块全量数据 | TC-RT-E2E-01/02 |
| partial | 快照到达且 failure=partial | 数据 + 失败类目横幅 | 单测覆盖；E2E mock 不模拟（边界） |
| retrying/failed | SSE error 或 REST 失败 | 更新失败横幅 + 最后成功时点 + 自动重试 | TC-RT-E2E-07（真实断网注入） |
| recovered | 重试成功 | 横幅消失、数据恢复 | TC-RT-E2E-08 |

## 页面级特殊态

| 状态 | 进入条件 | 用例 |
|---|---|---|
| 无应用引导 | 应用列表为空 | 单测 AC-008（mock 恒有 2 应用，E2E 不构造） |
| 应用不可用 | 快照 404 REALTIME_APP_NOT_FOUND | 单测 AC-011（mock 对任意 appKey 返回 200，E2E 不构造） |
| 无数据零值空态 | 快照 ok 但无样本 | 单测 AC-009（mock 恒有数据，E2E 不构造） |
| 首载失败 | 首连即失败 | 单测 AC-013（E2E 以 TC-07 近似：已加载后断流） |
| 快速切换竞态 | 连续切换 appKey | 单测 AC-010 + E2E TC-03 人工快速双击验证 |

## 迁移覆盖率口径

- E2E 可构造：idle→loading→ok、ok→retrying、retrying→recovered、ok→(切换)→ok —— 6/6 计划覆盖
- 仅单测覆盖：loading 细分、partial、无应用、应用不可用、零值空态、首载失败 —— 6 态
- 覆盖率计算：E2E 迁移 6/6=100%（构造范围内）；状态机全量 12/12（E2E 6 + 单测 6）
