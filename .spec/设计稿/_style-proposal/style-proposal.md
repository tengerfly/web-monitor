# 三套风格方案提案 — web-monitor 实时大屏

> UI-UX-Design 步骤 4 风格决策 Gate 产出物。默认「文字三方案 + 色板小样 HTML」（零额度）；出稿对比通道未启用。
> 风格情报：Superdesign 灵感库检索 20 条（相关方向：Neural Noir 暗色界面、Terminal 磷光绿、Midnight Editorial）；未命中「监控大屏」专属条目，按 PRD 约束推导。PRD 硬约束：深色高对比、远距离可读、异常醒目、看板常规框架内嵌。

## 〇、设计读（REQUIRED）

**读作：企业级前端监控平台给研发/运维值班者的健康度中控大屏，走「沉稳克制的深色监控中控」语言。**

受众 = 值班研发/运维（远距离观察、无人操作）+ 团队负责人（站会投屏）；气质取自 PRD：深色大屏视觉形态、关键数字远距离可辨、异常必须区别于常态地醒目。

## 一、方案 A：「中控青绿 · 值班监控台」

| 要素 | 内容 |
|---|---|
| 一句话气质 | 冷静的运维中控台：深海军蓝底上一组青绿健康色，数字大而安静，异常才出声 |
| 配色 | 背景 `#0B1220`（深海军） / 面板 `#111A2C` / 主色 `#2DD4BF`（青绿） / 文字 `#E6EDF7`、辅助 `#8B99B0` / 成功 `#34D399` 警告 `#FBBF24` 危险 `#F87171` |
| 排版 | Inter + 系统中文；数字大号加粗（28-40px 指标），正文 14px；密度紧凑（大屏信息密度优先）；圆角 4px |
| 交互气质 | 克制流动：数据刷新 200ms 淡入，异常条目出现一次高亮脉冲；悬停仅提亮边框 |
| 适用理由 | 青绿=「健康/在线」的直觉语义，与监控平台定位天然对齐；深海军底在电视/投屏上对比充足且不刺眼 |
| 开源体系基线 | Ant Design 5 暗色算法 token 基线，主色替换为 teal 系 |

## 二、方案 B：「曜石琥珀 · 指挥中心」

| 要素 | 内容 |
|---|---|
| 一句话气质 | 电力调度/指挥中心大屏：近黑曜石底、琥珀高亮，等宽数字仪表感，直角硬朗 |
| 配色 | 背景 `#121014`（曜石） / 面板 `#1A1720` / 主色 `#F59E0B`（琥珀） / 文字 `#F2EEE6`、辅助 `#9A937F` / 成功 `#A3E635` 警告 `#FBBF24` 危险 `#FB7185` |
| 排版 | JetBrains Mono 数字 + 系统中文正文；仪表化大数字（等宽、字距加宽）；密度高密（同屏信息量最大）；圆角 0-2px 直角 |
| 交互气质 | 静态为主：无入场动效，数据变化直接切换；告警横幅用琥珀呼吸灯式边框 |
| 适用理由 | 指挥中心语言在「挂屏值守」场景辨识度最高；直角+等宽传递仪表仪器的可靠感 |
| 开源体系基线 | 参照 Grafana 暗色仪表盘的信息层级，配色独立推导 |

## 三、方案 C：「冷辉电蓝 · 观测面板」

| 要素 | 内容 |
|---|---|
| 一句话气质 | 现代 SaaS 可观测面板的暗色版：深蓝黑底、电蓝高亮，图表主角，圆角适中 |
| 配色 | 背景 `#0A0F1E`（深蓝黑） / 面板 `#101828` / 主色 `#60A5FA`（电蓝） / 文字 `#E8EFFB`、辅助 `#7D8CA6` / 成功 `#4ADE80` 警告 `#FACC15` 危险 `#F87171` |
| 排版 | Inter + 系统中文；图表优先的层级（趋势区占比最大视觉权重）；密度适中；圆角 6px |
| 交互气质 | 编排最低限：首屏一次级联淡入（仅首次），曲线 300ms 平滑推进；悬停卡片浮起 1px |
| 适用理由 | 与 DataDog/Grafana 云面板的用户心智衔接最顺，研发熟悉度高；电蓝在深底上远距离辨识度好 |
| 开源体系基线 | 对齐 shadcn/ui 暗色 token 结构，主色换 blue 系 |

## 四、差异化声明（必填）

| 维度 | A 中控青绿 | B 曜石琥珀 | C 冷辉电蓝 |
|---|---|---|---|
| 视觉气质 | 冷静运维中控 | 指挥中心仪表 | 现代 SaaS 观测 |
| 主色相 | 青绿 `#2DD4BF` | 琥珀 `#F59E0B` | 电蓝 `#60A5FA` |
| 密度 | 紧凑 | 高密直角 | 适中 |
| 圆角语言 | 4px 小圆角 | 0-2px 直角 | 6px 圆角 |
| 数字字体 | Inter 加粗 | 等宽 JetBrains Mono | Inter + 图表优先 |
| 动效 | 克制流动 | 静态 | 最低限编排 |
