## 四、业务规则与状态机索引
| 对象/模块 | 规则/状态 | 锚点 |
|---|---|---|
| 统计范围 | 当日 00:00 起（服务端时区；趋势/错误流除外）【A1】 | M01 §5 |
| 趋势口径 | 以统计时点所在分钟为终点、含终点共 60 个点，无数据补空【A2】 | M01 §5 |
| 错误流 | 倒序、容量 50、含错误事件标识【A3】 | M01 §5 |
| Top 榜口径 | 接口名+方法聚合/次数/平均加载耗时 各前 5【A6】 | M01 §5 |
| 告警口径 | 未恢复（上限 100）+ 近 24h 记录（状态区分、预留不上墙）【A5/A11】 | M01 §5 |
| 活跃会话 | 统计时点前 5 分钟活跃、按会话标识去重【A4】 | M01 §5 |
| 接口成功率 | 沿用存量总览口径 | M01 §5 |
| 精度与单位 | 沿用存量展示口径；比率类无样本=空（零值例外） | M01 §5 |
| 零值语义 | 无数据=零值+补空序列（合法）；不可用=失败标记+最后时点；失败标记仅覆盖「服务可达但供数失败」 | M01 §5 |
| 更新通道状态机 | 更新中→更新中断→（恢复/已离开）；已离开=终态；新开视图跳详情不算离开；部分失败不改变通道状态 | overview §9.2、M02 §4.3 |
| 默认应用 | 进入/刷新均默认清单第一个；切换后全区块刷新（过渡期保留旧数据+加载反馈）【A9】 | M02 §5 |
| 时点展示 | 「时:分」+「服务端时间」标注，不换算本地时区 | M02 §5 |
| 横幅显隐 | 仅未恢复告警；全恢复后随下轮更新隐藏【A5】 | M02 §5 |
| 醒目触发 | 新增=与上一轮比对、持续一轮【A12】；横幅出现即醒目；指标卡=命中已启用告警规则阈值【A11】 | M02 §5 |
| 跳转规则 | 错误条目/告警横幅→新开视图跳既有详情页（通道保持）；其余不挂跳转 | M02 §5 |
| 展示底线 | 超长文本截断+可看完整内容；大数值沿用存量格式化 | M02 §5 |
