# web-monitor 实时大屏 原型说明

> 低保真可交互 HTML 原型，用于验证 PRD 需求闭环与业务逻辑。结构基线（非视觉交付稿）；载体划分见《布局清单.md》。

---

## 1. 原型概览

| 项 | 内容 |
|----|------|
| 需求名称 | web-monitor 实时大屏（V1） |
| 产品定位 | 看板内以近实时自动刷新呈现单应用线上健康度的深色大屏（六区块 + 异常跳转处置） |
| 端类型 | Web 端（桌面；PRD 明确移动端适配不做，故无双端问题） |
| 载体划分 | 见《布局清单.md》（核心产物） |
| 生成日期 | 2026-09-18 |

> **重要口径**：本原型为**结构基线**，按低保真规范使用极简浅色配色；PRD 的「深色大屏视觉形态」属于视觉基准，在 ⑥ UI/UX 设计阶段落地，勿以本原型配色为准。

## 2. 载体与跳转关系

| 页面文件 | 名称 | 入口（从哪进） | 出口（去向） |
|---------|------|---------------|-------------|
| index.html | 实时大屏页（唯一产品页面） | 看板左侧导航「实时大屏」 | 错误条目→error-detail-placeholder（新开视图）；告警横幅条目→alert-placeholder（新开视图）；无应用空态→access-guide-placeholder |
| error-detail-placeholder.html | 错误详情（存量占位） | index 错误条目（新开视图） | 关闭视图回大屏（页内提供返回兜底链接） |
| alert-placeholder.html | 告警管理（存量占位） | index 告警横幅条目（新开视图） | 同上 |
| access-guide-placeholder.html | 接入指引（存量占位） | index 无应用空态「去接入」 | 返回 index |

> 从浏览器打开 `index.html` 开始浏览。弹框/抽屉/卡片/列表均内嵌宿主页，不单独成文件。

## 4. 使用说明

- 直接用浏览器打开 `index.html` 即可，无需构建工具；
- **右下角「原型状态模拟器（非产品功能）」**用于演示六种状态：正常 / 更新失败（有最后时点）/ 首次加载失败（暂无已加载数据）/ 部分类目失败（达标率区块就地标注）/ 应用无数据（空态）/ 平台无应用（引导页）；
- 「暂停自动更新演示」开关控制每 6 秒一轮的自动更新模拟（时点刷新、错误流新增并高亮一轮、趋势推进）；
- 左侧导航中标注「存量页」的项为看板既有页面，不属本原型范围，置灰不可点；
- 本原型为**低保真原型**（结构基线，非高保真稿），仅用于验证需求闭环与业务逻辑，**不是视觉交付稿**——视觉基准看 `.spec/设计稿/`。
