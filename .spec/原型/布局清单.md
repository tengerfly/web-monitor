## 二、页面间跳转关系（文字版站点地图）

```
index.html（实时大屏页，入口）
  ├─ 错误滚动流条目点击（新开视图） → error-detail-placeholder.html
  ├─ 告警横幅条目点击（新开视图） → alert-placeholder.html
  ├─ 无应用空态「去接入」（当前视图） → access-guide-placeholder.html
  └─ 左侧导航「实时大屏」= 当前页（高亮；其余导航项为存量页、原型内置灰不可点）
error-detail-placeholder.html → 提示关闭视图返回大屏（+ 返回 index 链接兜底）
alert-placeholder.html       → 提示关闭视图返回大屏（+ 返回 index 链接兜底）
access-guide-placeholder.html → 返回 index
```

## 三、载体判定依据
- 实时大屏 = 重内容、高频、需独立导航位 → 独立页面；六类内容信息量小且与宿主强相关 → 页内区块/卡片/列表，不拆独立页；
- 出口详情页 = 存量系统页面 → 原型占位保闭环（不做真实详情，避免越界加戏）。

## 四、呈现与确认规则
- 本清单由 AI 基于 PRD 推荐并随原型一并交付；本轮为「一路到测试」连续模式，用户已在 PRD S2 拍板全部布局关键决策（深色 TV 形态 / 单应用+切换器 / 全量六模块 / 导航内常规页），载体划分均为其直接推导——如对划分有异议，回本步骤调整并同步回写。
- 清单 ↔ 原型一致：后续调整必须双向同步。

## 五、红线自查
1. PRD 页面/功能无静默丢弃（见覆盖核对表）；
2. 无孤儿载体（三个占位页均有入口与出口）；
3. 独立页面数 = 4（1 产品页 + 3 占位页），以本清单为准。
