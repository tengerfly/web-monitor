# web-monitor 上报协议 v1

> 本协议是 **SDK / 服务端 / 看板 三方的唯一契约**，类型定义源码位于 `packages/types`，任何一方变更必须先改此处。

## 1. 传输

| 项 | 值 |
|---|---|
| 上报入口 | `POST {host}/api/v1/ingest` |
| 配置下发 | `GET {host}/api/v1/config?appKey=xxx&sdk=0.1.0` |
| 请求头 | `Content-Type: application/json`；Beacon 场景允许 `text/plain` |
| 鉴权 | body 内 `appKey`（预留 `X-App-Sign` 签名扩展位） |
| 编码 | UTF-8；单次请求 ≤ 64KB（超限由 SDK 拆批） |
| 超时 | 默认 5000ms，失败进本地队列重试 |
| 幂等 | `event.id` 为 UUID，服务端按 `id` 去重（窗口 5 分钟） |

## 2. 信封结构

**设计要点**：同一批次内共享的字段（会话、用户、设备上下文）只传一次，放在 `common` 中，`events` 只携带差异字段。相比每事件携带完整上下文，平均可减少 60%+ 载荷。

```jsonc
{
  "appKey": "wm_2f8a1c9d4e",
  "sdk": { "name": "@web-monitor/core", "version": "0.1.0" },
  "common": {
    "appVersion": "1.4.2",
    "env": "production",
    "sessionId": "s_1712345678901_ab12cd",
    "userId": "u_10086",
    "anonymousId": "a_9f3c2b1a",
    "pageId": "/order/detail",
    "url": "https://shop.example.com/order/detail?id=88",
    "referrer": "https://shop.example.com/cart",
    "context": {
      "device": { "type": "desktop", "brand": "Apple", "model": "Macintosh", "screen": "2560x1440", "viewport": "1440x820", "dpr": 2, "orientation": "landscape" },
      "os": { "name": "macOS", "version": "14.5" },
      "browser": { "name": "Chrome", "version": "126.0.0", "engine": "Blink" },
      "network": { "type": "wifi", "effectiveType": "4g", "rtt": 50, "downlink": 10, "saveData": false, "online": true },
      "app": { "name": "shop-web", "version": "1.4.2", "env": "production" },
      "sdk": { "name": "@web-monitor/core", "version": "0.1.0" }
    },
    "custom": { "channel": "wechat" }
  },
  "events": [
    { "id": "e_1", "type": "performance", "category": "web-vital", "timestamp": 1712345678901, "traceId": "t_abc", "payload": { "metric": "LCP", "value": 1832, "rating": "good" } }
  ]
}
```

### 2.1 `common` 字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `appVersion` | string | 否 | 业务应用版本（用于版本对比与 SourceMap 定位） |
| `env` | string | 是 | `production` / `staging` / `development` |
| `sessionId` | string | 是 | 会话 ID，30 分钟无操作后重建 |
| `userId` | string | 否 | 业务登录用户 ID，`identify()` 注入 |
| `anonymousId` | string | 是 | 本地持久化匿名 ID（localStorage） |
| `pageId` | string | 是 | 当前页面标识（路由 path，不含 query） |
| `url` | string | 是 | 完整 URL（query 中敏感参数会被脱敏） |
| `referrer` | string | 否 | 来源页 |
| `context` | object | 是 | 环境上下文，结构见上 |
| `custom` | object | 否 | 业务自定义公共属性（`setContext()` 注入） |

### 2.2 `events[]` 字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | string | 是 | 事件唯一 ID |
| `type` | enum | 是 | `performance` / `error` / `behavior` / `replay` / `custom` |
| `category` | string | 是 | 子类别，决定 payload 结构 |
| `timestamp` | number | 是 | 事件发生时间（ms） |
| `traceId` | string | 否 | 链路 ID，跨事件/跨端关联 |
| `payload` | object | 是 | 类别专属载荷 |

## 3. 事件类别与载荷

### 3.1 performance（type = `performance`）

| category | payload 字段 |
|---|---|
| `web-vital` | `metric`(LCP/INP/CLS/FCP/TTFB/FID) `value` `rating`(good/needs-improvement/poor) `navigationType` `delta` |
| `navigation` | `navigationType` `redirect` `dns` `tcp` `tls` `request` `response` `firstByte` `domParse` `domContentLoaded` `load` `pageLoad` `fp` `fmp` `tti` `transferSize` `decodedBodySize` |
| `resource` | `name` `initiatorType` `duration` `startTime` `transferSize` `encodedBodySize` `decodedBodySize` `protocol` |
| `long-task` | `count` `totalDuration` `maxDuration` `tbt` `entries[]` |
| `fps` | `fps` `sampleDuration` `frames` `jankCount` `maxFrameDuration` |
| `memory` | `usedJSHeapSize` `totalJSHeapSize` `jsHeapSizeLimit` `usage` |
| `api` | `method` `url`(归一化) `status` `ok` `duration` `requestSize` `responseSize` `traceId` `errorType` |
| `route-change` | `from` `to` `type`(pushState/popstate/replaceState/hashchange) `duration` |
| `network` | `effectiveType` `rtt` `downlink` `saveData` `online` `type` |
| `white-screen` | `url` `duration` `pointCount` |
| `custom-metric` | `metric` `value` `unit` `tags` |

### 3.2 error（type = `error`）

所有错误类载荷都额外携带 **溯源三件套**：`breadcrumbs`、`snapshot`、`fingerprint`。

| category | 专属 payload 字段 | 溯源字段 |
|---|---|---|
| `js-error` | `message` `name` `type`(error/unhandledrejection) `stack` `filename` `lineno` `colno` `frames[]` `level` `mechanism` | ✓ |
| `resource-error` | `tagName` `url` `selector` `errorType`(network/cors/404/unknown) | ✓ |
| `request-error` | `method` `url` `status` `statusText` `errorType`(http/timeout/network/cors/business) `responseBody` | ✓ |
| `console-error` | `level`(error/warn) `args[]` | ✓ |
| `custom-error` | `message` `name` `stack` `level` `extra` | ✓ |

**`breadcrumbs[]`**（错误前最近 N 条操作，默认 20）：

| 字段 | 说明 |
|---|---|
| `id` | 唯一 ID |
| `type` | `click` / `route` / `request` / `console` / `input` / `navigation` / `custom` / `error` |
| `message` | 可读描述，如 `点击 button.submit-btn` |
| `level` | `info` / `warning` / `error` |
| `timestamp` | 发生时间 |
| `data` | 结构化细节（选择器、URL、状态码、耗时等） |

**`snapshot`**（错误现场）：

| 字段 | 说明 |
|---|---|
| `memory` | JS 堆使用情况（浏览器支持时） |
| `network` | 当时的网络类型 / RTT / 下行带宽 |
| `visibility` | `visible` / `hidden` / `prerender` |
| `route` / `title` / `viewport` / `userAgent` | 页面现场 |
| `lastRequest` | 最近一次请求（含失败）的 method/url/status/duration |
| `lastSuccessRequest` | 最近一次成功请求 |

### 3.3 behavior（type = `behavior`）

| category | payload 字段 |
|---|---|
| `pv` | `path` `title` `referrer` `fromPath` `duration`(上个页面停留) `sessionDuration` `isEntry` |
| `route-change` | `from` `to` `type` `duration` |
| `click` | `selector` `xpath` `text` `tagName` `attributes`(data-* 优先) `x` `y` `pageX` `pageY` |
| `exposure` | `selector` `text` `ratio` `enterTime` `leaveTime` `duration` |
| `scroll` | `depth` `maxDepth` `scrollTop` `documentHeight` `viewportHeight` |
| `form` | `selector` `action`(focus/blur/change/submit/submit-fail) `field` `value`(默认脱敏) `duration` |
| `console` | `level` `args[]` |
| `visibility` | `state` `duration` |
| `stay` | `path` `duration` `visibleDuration` `maxScrollDepth` |
| `custom` | `eventName` `properties` `category`(业务自定义分组) |

### 3.4 replay（type = `replay`）

数据结构**对齐 rrweb**，保证可无缝切换社区播放器。

| category | payload 字段 |
|---|---|
| `replay-meta` | `startTime` `endTime` `duration` `width` `height` `totalChunks` `reason`(duration/size/unload) |
| `replay-chunk` | `index` `startTime` `endTime` `events[]` `reasons[]` |

`events[]` 元素：`{ type, timestamp, delay?, data }`

| `type` | 含义 | 备注 |
|---|---|---|
| 0 | DomContentLoaded | |
| 1 | Load | |
| 2 | FullSnapshot | `data.node` 为序列化后的 DOM 树 |
| 3 | IncrementalSnapshot | `data.source` 区分变更类型 |
| 4 | Meta | `data = { href, width, height }` |
| 5 | Custom | `data = { tag, payload }` |

IncrementalSnapshot 的 `data.source`：

| source | 含义 |
|---|---|
| 0 | Mutation（`adds` / `removes` / `texts` / `attributes`） |
| 1 | MouseMove |
| 2 | MouseInteraction（`type`: 0 MouseUp / 1 MouseDown / 2 Click / 3 ContextMenu / 4 DblClick / 5 Focus / 6 Blur / 7 TouchStart / 9 TouchEnd） |
| 3 | Scroll |
| 4 | ViewportResize |
| 5 | Input |
| 6 | TouchMove |
| 7 | MediaInteraction |

**DOM 节点序列化格式**（rrweb 兼容）：

```jsonc
// Element
{ "type": 2, "tagName": "div", "attributes": { "class": "box" }, "childNodes": [ /* ... */ ] }
// TextNode
{ "type": 3, "textContent": "hello" }
// Comment
{ "type": 5, "textContent": "..." }
```

## 4. 响应

```jsonc
// POST /api/v1/ingest
{ "code": 0, "message": "ok", "data": { "accepted": 12, "dropped": 0, "sampleRate": 1 } }
```

| code | 含义 |
|---|---|
| 0 | 成功 |
| 40001 | appKey 缺失或非法 |
| 42901 | 触发限流（SDK 应退避重试） |
| 50000 | 服务端内部错误（SDK 入本地队列等待补报） |

`GET /api/v1/config` 返回远程配置：

```jsonc
{
  "code": 0,
  "data": {
    "sampleRate": 1,
    "plugins": { "performance": true, "behavior": true, "error": true, "replay": false },
    "performance": { "sampleRate": 1, "thresholds": { "LCP": 2500, "INP": 200, "CLS": 0.1, "FCP": 1800, "TTFB": 800 } },
    "behavior": { "sampleRate": 0.3, "ignoreSelectors": [".no-track"] },
    "error": { "sampleRate": 1, "maxBreadcrumbs": 20, "minLevel": "warning" },
    "replay": { "sampleRate": 0.1, "maskAllInputs": true },
    "maskRules": { "selectors": [".sensitive"], "attributes": ["data-secret"], "fields": ["password", "token", "idCard"] },
    "updatedAt": "2026-09-17T10:00:00.000Z"
  }
}
```

## 5. 可靠性与兼容

| 场景 | 约定 |
|---|---|
| 上报失败 | 指数退避重试 3 次；仍失败则写入本地队列（上限 200 条 / TTL 24h），下次启动补报 |
| 页面卸载 | `visibilitychange:hidden` 与 `pagehide` 时立即 `sendBeacon` 冲刷 |
| 字段不识别 | 服务端丢弃未知字段，不报错；客户端忽略未知响应字段 |
| 协议演进 | 新增 `category` 与 payload 字段视为**向下兼容**；破坏性变更需升 `/api/v2` |
| 体积保护 | 单事件 `payload` 序列化后 > 32KB 触发截断（保留关键字段 + `__truncated: true`） |
| 隐私 | `password` 类字段永不采集；`maskRules` 命中的值与 DOM 文本替换为 `***` |
